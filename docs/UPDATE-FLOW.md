## 安装鉴权与后台流程

1. 网页 POST `/__preview/install` 必须同源、带固定请求标头和有效管理员登录 Cookie。
2. 使用固定运行程序自己的 `runtime/data/mmwx.db` 中 sessions/users 校验会话、有效期、启用状态和 admin 角色，不信任前端角色，不另设网页密码。
3. 预检查 systemd 服务可用，再从本仓库固定发布地址下载。目标版本变化时拒绝安装并要求重新检查。
4. 校验 Ed25519 签名、白名单、体积、版本和逐文件 SHA-256；普通更新必须递增，明确的强制重装允许相同版本，始终拒绝降级。
5. 共用文件锁、SQLite 一致性快照、代码备份、原子替换和待重启标记。保留账号、许可证、主题和壁纸。
6. 返回重启状态后由 systemd 重启；页面等到 running/installed 匹配目标且 pending=false 才显示成功。最多等待 120 秒。

命令行仍支持 `python3 updater.py install --latest --restart` 或指定签名包。旧维护 API 仅为旧版兼容保留，不再出现在网页上。官方二进制的 apply 接口继续拦截，避免覆盖本部署。官方内网端口不要对公网开放。
